# GitGalaxy v1.0.0

GitGalaxy v1.0.0 是首个公开版本：将精选 GitHub 开源项目呈现在可交互的三维宇宙中。

## Highlights

- 使用 React、TypeScript、Three.js 与 React Three Fiber 构建的三维星图。
- Repository 的 Star、Fork、主要语言等真实数据映射为恒星外观。
- 支持项目搜索、键盘快捷键、相机聚焦、详情查看与跳转 GitHub。
- Collector 通过 GitHub API 生成、筛选、去重并校验 `universe.json`。
- 支持低、中、高画质及 WebGL 降级状态。
- GitHub Actions 提供持续集成、GitHub Pages 自动部署和每周数据更新。

## Data and privacy

数据仅来自 GitHub 公共 API。所有实际 Token 都存放在本地 `.env` 或 GitHub Actions Secrets 中；仓库仅保留 `.env.example`。

## Release gate

- 正式 `v1.0.0` 仅在数据集扩展至约 5,000 条、通过质量校验，并完成目标设备性能验证后发布。
- 当前随仓库提供的 100 条已校验记录仅用于功能与部署验收；若提前开放试用，应发布为预发布版本，例如 `v1.0.0-preview.1`。
- 视觉效果与帧率会因浏览器、GPU 和设备性能而异。

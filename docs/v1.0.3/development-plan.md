# GitGalaxy V1.0.3 国际化计划

## 版本信息

| 项目 | 内容 |
|---|---|
| 版本 | V1.0.3 |
| 状态 | 已规划 |
| 计划日期 | 2026-10-11 |
| 类型 | 补丁版本：中英双语体验与文档可访问性 |
| 基线版本 | V1.0.2 |

## 目标

让 GitGalaxy 的产品界面与 GitHub 仓库文档均可在简体中文和英语之间切换或访问。国际化只翻译 GitGalaxy 自己的文字；采集到的 GitHub Repository 名称、描述、topics、语言名称和时间数据保持原样，避免机器翻译造成事实失真。

## 范围

### 1. 页面国际化

- 支持 `zh-CN` 与 `en` 两种界面语言。
- 第一次访问时优先使用浏览器语言；不支持的语言回退到英语。
- 在页面中提供明确的语言切换入口，并将用户选择保存到 `localStorage`；刷新、重访与 GitHub Pages 静态部署均应保留该选择。
- 所有 GitGalaxy 自有可见文字进入翻译资源：顶栏、主视觉、搜索、详情面板、语言图例、画质控制、加载/错误/降级状态、键盘提示和无障碍标签。
- 翻译键使用语义化命名并集中维护，组件内不再散落中英文硬编码文本。

### 2. 文案与数据边界

| 内容 | 是否翻译 | 原则 |
|---|---:|---|
| 按钮、提示、状态、无障碍文本 | 是 | 跟随已选界面语言 |
| GitGalaxy 品牌名、产品名 | 否 | 始终为 `GitGalaxy` |
| Repository 全名、URL、stars、forks、topics | 否 | 保留 GitHub 原始事实 |
| Repository 描述与主要语言 | 否 | 不进行自动机器翻译 |
| 日期与数字显示格式 | 是 | 使用所选语言的 `Intl` 格式化 |

### 3. GitHub 仓库文档国际化

- `README.md` 保持英文入口；新增 `README.zh-CN.md`。两份文件在顶部相互链接，并维持相同章节结构、截图、版本信息和链接。
- `docs/README.md` 保持简体中文文档索引；新增 `docs/README.en.md`，在顶部互相链接。
- 每个版本目录的 `development-plan.md`、`release-checklist.md`、`release-notes.md` 均提供对应的英文副本，使用 `.en.md` 后缀；中文版继续使用既有文件名。
- 为 `v1.0.0`、`v1.0.1`、`v1.0.2` 和 V1.0.3 文档补齐英文副本。每份中英文文档的标题、版本、发布日期、状态和链接必须一致。
- `CONTRIBUTING.md`、Issue/PR 模板和后续新增的仓库级说明也纳入双语覆盖；许可证正文不翻译，保留官方 MIT 文本。

### 4. 技术方案

- 采用 `i18next`、`react-i18next` 与 TypeScript 翻译资源；依赖安装由维护者手动执行，不在本计划中自动安装。
- 翻译文件按语言、功能域组织，例如 `src/i18n/locales/en/common.ts` 与 `src/i18n/locales/zh-CN/common.ts`。
- 在应用根部初始化语言环境，业务组件通过 `useTranslation` 获取文字；禁止以页面 URL 作为唯一语言状态，保证 GitHub Pages 静态路径兼容。
- 使用 `Intl.NumberFormat` 与 `Intl.DateTimeFormat` 格式化数字和日期，禁止为不同语言复制计算逻辑。
- 为翻译键完整性和语言切换增加单元测试；端到端测试覆盖浏览器语言回退、手动切换、刷新保留和关键无障碍标签。

## 非目标

- 不增加第三种语言，不接入在线翻译 API，也不翻译 GitHub 的原始项目数据。
- 不改变采集器数据结构、搜索/排序语义、星图视觉规则或 V1.0.2 的并发采集范围。
- 不以国际化为由修改已发布版本的事实性发布记录；仅新增对应语言副本并保留原版内容。

## 实施顺序

1. 确定中英术语表、默认语言与翻译键命名约定；安装并配置国际化依赖。
2. 提取 UI 固有文案，接入浏览器语言检测、手动切换与本地持久化。
3. 接入本地化的数字、日期和无障碍标签，完成窄屏语言切换体验。
4. 新增双语 README、文档索引和各版本文档副本，添加双向跳转链接。
5. 执行翻译键、切换持久化、端到端和文档链接检查；更新发布说明与验收清单。

## 测试与发布门槛

- 单元测试：两种语言均拥有完整翻译键；默认语言、回退逻辑和 `localStorage` 持久化正确。
- E2E：语言切换后关键 UI 立即更新；刷新后语言保持；键盘搜索、详情和画质控制在两种语言下可用。
- 文档检查：中英 README 与文档索引互相可达；所有版本文档具有成对副本，内部链接无 404。
- 人工检查：窄屏不遮挡语言切换；中英文长度变化不导致布局溢出；GitHub Pages 子路径下资源与语言状态正常。
